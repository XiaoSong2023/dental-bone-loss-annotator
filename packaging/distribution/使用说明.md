# 牙槽骨吸收测量 1.3.0 预览版

只保留一个软件入口“牙槽骨吸收测量”。不需要另装Python或CUDA，所有运算在本机执行。

## 开始标注

1. 打开软件后是空白抓手状态，不自动打开上次项目，也不自动分割或标点。
2. 在“项目”菜单新建或打开项目，导入/选择全景片。
3. 可以按T手工画框选牙；也可以点击“自动分割牙齿”，生成每颗牙的完整轮廓和矩形框。分割只做选牙，不生成标注点。
4. 双击牙框直接放大进入手工标定；重叠处出现“方框A / B / … / 取消”，选中需要的牙。
5. 保持原来近中、远中各四点：CEJ、CEJ下2mm、AC、根尖。四个计算公式不变。本牙应标的点全部完成，或明确跳过看不清的一面后，自动进入下一牙；最后一牙完成后点击“完成标定”。拖动已有点不会触发跳牙。
6. 点击保存与导出，生成标注点和计算结果。

## 两个自动按钮

- **自动分割牙齿**：仅生成牙框与轮廓，完成后保存。不会自动接着标点。
- **自动标注**：仅在已有牙框上运行CEJ、骨水平、根尖三点候选模型，不重新分割、不改变当前牙框。需要先手工框选或自动分割；不点击就不自动标注。CEJ下2mm仍需手工标，不用固定比例补造。

自动标点有现成牙齿轮廓时会贴合轮廓；只有人工框、没有分割轮廓时保留模型原点。自动候选仍会遗漏或偏位，需要人工调整；图像左/右组需要人工确认近中/远中，牙位号也可以修改。轮廓贴合不能证明CEJ或真正牙槽嵴顶准确。

## 看片、重画与撤销

主窗口默认抓手H，左键拖动自由移动图像；中键拖动、触控板双指水平滑动也可以平移。普通垂直滚轮缩放，Ctrl+0适配全图。放大窗口可切换“抓手平移”和标点，左键拖动现有点调整坐标，手工点可自由定位。

按T重画：与一个旧框明确对应时直接替换，并保留该牙的点；与多个旧框对应时先选择替换对象；没有对应旧框时新增。Ctrl+Z或“撤销框选”恢复上一笔框选，可找回机器初始框；保存并重开后仍保留撤销记录。

放大标定窗口的“完成标定”应用本次修改；“取消”放弃本次窗口修改。

## 保存与导出

CSV恢复为summary.csv和sites.csv两个表；Excel恢复为“患者级汇总”和“位点级明细”两个工作表。位点表输出当前CEJ、CEJ下2mm、AC、根尖坐标和原来的计算结果，不含矩形四角或原始预测坐标。

单片JSON同样只导出已标注的位点与相关基本信息/派生结果，不含牙框、轮廓、历史候选或原始预测坐标。坐标基于原图像素，不是屏幕位置。尚未标点的空牙框不作为标点导出；缺失点保持空白。

重新导出CSV时，若目录里存在软件1.1/1.2生成的旧boxes.csv，会移除识别出的旧牙框表；其他自有文件不删除。

项目内部仍保存框、轮廓、原始模型结果与编辑历史，用于继续标注、复核和撤销。继续编辑请打开原项目；移动时复制整个项目文件夹，包括annotations、images、runs等。单片JSON是坐标导出，不是完整可编辑项目备份。

模型来源与SHA-256见models/README.md，许可见THIRD_PARTY，集成源码见SOURCE。本轮未重新训练、上传影像或使用云GPU。
