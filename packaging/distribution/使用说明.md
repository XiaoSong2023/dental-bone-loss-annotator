# 牙槽骨吸收测量 1.2.0 预览版

一个安装包提供两个桌面入口，共用软件与已训练模型，无需另装 Python 或 CUDA。

- **牙槽骨吸收测量（分割人工版）**：自动生成牙齿轮廓和方框，不运行自动点模型；双击牙框后手工标四点。直接运行 exe 默认进入此版。
- **牙槽骨吸收测量AI**：自动分割并生成 CEJ、骨水平、根尖三点候选，候选投影到对应牙齿轮廓，之后人工复核。自动模型不生成第四个 CEJ 下 2mm 点。

## 看片与标点

1. 新建或打开项目，导入全景片，选中当前图像。
2. 点击底部自动分割按钮，完成后自动保存。处理期间可以取消。
3. 双击单牙框直接放大；双击处有重叠牙框时，选择“方框 A / B / …”或取消。
4. 放大窗口保持原有四点采集顺序与四个测量公式。点上左键拖动调整；手工点可放在需要的位置，不强行吸附轮廓。
5. 自动候选的图像左/右组需人工确认近中/远中，牙位号可修改。按“完成标定”应用，按“取消”放弃本次窗口修改。

中键拖动、触控板双指滑动可平移。主窗口默认抓手模式，左键抓住图像自由移动；H 切抓手，T 切手工框选。放大窗口也有“抓手 / 标点”切换。鼠标滚轮缩放，Ctrl+0 适配全图；放大窗口 F 适配当前牙框。

## 重画牙框与撤销

按 T 后重新画框：与单个旧牙框明确对应时直接替换，保留该牙所有点；与多个牙框对应时先选要替换的框。没有对应旧框时新增牙框并填写牙位号。

点击“撤销框选”或 Ctrl+Z 撤销上一笔框选，可逐笔恢复原框，保存并重新打开项目后仍有效。撤销框选不会删除随后采集的点。初次自动框另存于 initial_auto_roi，当前框与四角始终随修改更新。

## 自动候选与轮廓约束

自动候选版先执行真实训练模型，再将每个候选投影到第一轮牙齿分割轮廓的最近线段。原始预测 raw_xy、投影 projected_xy、当前坐标、移动距离和人工修改历史分别保留。分数仍是原模型分数。

旧项目可用“编辑 → 候选点贴合牙齿轮廓”，只校正未被人工修改或复核的模型候选，缺点不会凭空生成。人工版不执行此操作，也不删除项目内已有的历史标注。

**贴合牙齿轮廓只是几何约束，不等于已经准确识别 CEJ 或牙槽嵴顶。** 牙齿分割不包含独立的牙槽骨/CEJ解剖分割；骨嵴顶与牙齿边缘上的骨水平交点不能混为一谈。偏移较大的候选尤其需要检查。无可靠模型候选的牙位仍需人工补标，不用固定比例填点。

## 保存与导出

保存项目，再导出 CSV、Excel 或单片 JSON。CSV 有 boxes.csv，Excel 有“牙框坐标”工作表，JSON 有 roi_corners：左上、右上、右下、左下，均为当前导入图像的原始像素坐标，不是屏幕坐标。无标点的牙框也会导出。

完整模型结果、mask、裁剪及坐标变换保存在项目 runs 目录；移动项目时复制整个项目文件夹。单片 JSON 不等于包含全部二进制 mask 的完整项目包。1.2 使用 schema 5，可读旧标注；旧程序不支持新增的撤销和来源字段，请用新版继续处理已由新版保存的项目。

所有运算在本机执行，本次没有重新训练、上传影像或使用云GPU。覆盖数量属于候选检出结果，尚未完成全景片独立医学准确率验证。
