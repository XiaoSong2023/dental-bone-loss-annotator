# 牙槽骨吸收测量 AI 预览版

双击安装包，安装后打开“牙槽骨吸收测量 AI 预览版”。已包含 CPU 运行环境和两份训练权重，无需另装 Python 或 CUDA。

1. 新建或打开项目，导入全景片，选中要处理的图像。
2. 点击“自动分割与三点候选”，等待完成。处理期间可以取消；一次处理当前一张图像。
3. 自动结果显示牙框、分割轮廓、FDI 候选和 CEJ／骨嵴／根尖三点。部分牙齿可能只有牙框，缺点需要补标。
4. 双击牙框进入复核，拖动标点修正位置，修改牙位；确认图像左右组对应的近中／远中。应用后保存；取消复核不改动原标注。
5. 需要时手动画框、补牙、补点。框的左上、右上、右下、左下四角坐标自动记录。
6. 保存项目，再导出 CSV、Excel 或单片 JSON。CSV 另有 boxes.csv，Excel 有“牙框坐标”工作表；JSON 包含 roi_corners。所有点和框坐标均对应当前导入影像的原始像素尺寸，不是屏幕截图坐标。

自动点旁的“候”表示待复核。模型原始坐标与当前人工调整坐标分别保存；完整模型结果、原始 mask、裁剪及变换记录保存在项目 runs 目录。移动项目时请一起复制整个项目文件夹。

三个自动点不包含旧软件里的“CEJ 下 2mm”。使用需要第四点的公式时，仍需人工标出该点。没有进行全景片标注准确率验证；漏检与错标需要人工复核，不把空缺点自动补成固定位置。

首次运行及系统繁忙时可能较慢。本机验证单张全景片约 100 秒、模型进程峰值约 1.4 GiB。旧版软件与新版本采用独立安装目录；既有工程保存前建议保留原文件副本，旧版不支持新版本 schema 4 的来源与候选字段。

模型来源、SHA-256 与许可声明见 models/README.md，依赖许可见 THIRD_PARTY，本次集成源码见 SOURCE。
