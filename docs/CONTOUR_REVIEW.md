# 轮廓约束的含义与训练边界

用户本轮优先要求不重新训练。1.2 保留原训练权重和分割结果：只改候选归属、有限额外上下文推理及点的几何投影。分割人工版只执行分割，四点/四公式保持不变。

对模型原图点 p，遍历该牙全部闭合轮廓线段 a→b：

`t = clamp(dot(p-a, b-a) / dot(b-a, b-a), 0, 1)`，`q = a + t*(b-a)`。

选欧氏距离最小的 q；退化线段使用端点。使用浮点线段投影，而非只挑最近轮廓顶点。原始 p、校正 q、轮廓SHA256、线段索引/t、移动距离及分数分别保存。人工作出的后续修改不强制贴线。旧项目菜单只调整尚未人工编辑/复核的模型候选。

这一步保证的是“候选中心在显示的牙齿轮廓上”。它无法从牙齿外轮廓唯一推出 CEJ 和骨嵴位置，也没有进行医学准确率验证。牙齿边缘上的骨水平交点和牙槽嵴真正顶点需要按标注定义区分。后端始终保留骨水平模型原点，不能把投影点当作新的人工真值或把投影距离当作置信分数。

当前真实样片：31牙；原版本11牙有完整三点候选，新版本15牙。其余16牙依然缺完整组三点；UI选择每个图像侧的最高分整组后显示60点。覆盖不是准确率或真实召回率，因为没有独立人工真值。

如果下一阶段训练，建议保存原片、独立分割mask、人工复核后的CEJ/骨嵴/根尖坐标与可见性，单独保存轮廓辅助输入；不要仅保存把红绿线烧进灰度片的截图。这是工程设计建议：彩线会改变原图强度并遮住局部细节，而独立mask可以切换/消融验证。新输入或mask通道需要相应训练适配，现有三通道权重不会自动理解新的通道定义。

样本量能否减少、准确率能否提高，需要保持病例级独立验证集，分别比较原片输入与轮廓辅助输入；不能预先保证。分割线和未经复核的自动投影点本身不能代替CEJ/骨嵴的专家标注。现有纯人工流程保存的原图坐标可以作为后续整理标签的基础，本轮没有自动启动训练。
